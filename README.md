# DATA 602 Assignment 8

This project explores NYC 311 Service Request data using Python, pandas, matplotlib, and seaborn.

## Project Overview
The goal of this assignment was to practice data exploration, data wrangling, and data visualization using a public dataset.

## Dataset
The dataset used is the NYC 311 Service Requests dataset from NYC Open Data.

Dataset link: https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9/about_data

## Tools Used
- Python
- pandas
- matplotlib
- seaborn
- Google Colab

## Visualizations
This notebook includes:
- A line chart showing NYC 311 complaints over time
- A bar chart showing the top complaint types
- Seaborn versions of the same visualizations

## Key Takeaway
This assignment helped me better understand how visualizations can make real-world data easier to interpret. It also helped me compare matplotlib and seaborn, including when one tool may be better than the other.
